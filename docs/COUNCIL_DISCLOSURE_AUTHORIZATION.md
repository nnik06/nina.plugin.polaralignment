# Council Disclosure Authorization

The project owner authorizes sharing all information from this project with the
Claude and Gemini council reviewers for the lifetime of this project.

This includes private source code, patches, logs, hardware observations,
workflow details, calibration data, test artifacts, and incident summaries.

The authorization is limited to council review. Claude and Gemini remain
read-only reviewers and must follow the project's bridge provenance, safety,
and confidentiality procedures. This authorization does not relax those
procedures or permit reviewers to operate hardware or modify the repository.
